## 🇬🇧 English

### 📌 About the Project
**FIFA to PES Face Converter Tool** is a fast, automated utility designed for PES (Pro Evolution Soccer / eFootball) facemakers and modders. It converts 3D player face models and textures from **FIFA / EA Sports FC** into **PES-compatible** formats with a **single click**—eliminating tedious manual UV mapping and mesh adjustments.

### ✨ Key Features
* ⚡ **One-Click Conversion:** Streamlined workflow from FIFA/FC face files to PES format.
* 🎨 **Texture & UV Optimization:** Automatically adapts skin textures and UV layouts for PES engines.
* 🛠️ **Modder-Friendly:** Built to save hours of manual Blender/3D modeling work.
* 🎯 **High Accuracy:** Preserves original facial structure, proportions, and details.
